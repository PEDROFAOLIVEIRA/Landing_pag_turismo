# Landing Page de Turismo

Projeto desenvolvido como prática inicial de HTML e CSS, com o objetivo de construir uma landing page de turismo apresentando a cidade de Busan, na Coreia do Sul.

Este repositório faz parte da minha jornada de estudos em desenvolvimento Full Stack, com foco em compreender a estrutura de páginas web, organização semântica do HTML e estilização com CSS.

---

## Objetivo do projeto

O objetivo principal deste projeto é praticar os fundamentos de criação de páginas web, incluindo:

- Estruturação de conteúdo com HTML;
- Uso correto de tags semânticas;
- Organização de seções da página;
- Inserção de imagens;
- Criação de listas;
- Estilização com CSS externo;
- Aplicação de espaçamentos, cores, fontes e hierarquia visual;
- Melhoria gradual da organização do código.
